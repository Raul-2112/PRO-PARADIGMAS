# Fuentes médicas de la base de conocimiento

Cada enfermedad lleva su hecho `fuente/2` en `backend/kb/`. Esta lista consolida las fuentes para el informe técnico.

| Fuente | Enfermedades |
|---|---|
| MinSalud Colombia, Guía de práctica clínica de dengue | dengue |
| MinSalud Colombia, Infección respiratoria aguda | resfriado |
| OMS, Nota descriptiva Gripe estacional | gripe |
| OMS, Tratamiento de la diarrea | gastroenteritis |
| OMS, Cefaleas: nota descriptiva | migraña |

> Los pesos de los síntomas los define el equipo a partir de estas fuentes; son estimaciones del modelo, no probabilidades clínicas.
